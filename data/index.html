Race data & JSON API

One public file powers the whole race. People, apps and AI agents are welcome to use it.

Open race.json

Endpoint

GET https://www.greatairace.com/data/race.json returns application/json. No key, no sign-up. Current data is as of Nov 17, 2026 (meta.as_of). Update target: daily. Please cache and credit "Great AI Race (greatairace.com)".

Structure

  • meta: as_of, version, lane definitions, default weights, update_cadence, index_note and flagged conflicts.
  • racers[]: one object per lab. Each metric is a fact object: {"value", "source", "date", "note"}. value: null means not disclosed; we never estimate.
  • racers[].scoring: inputs (the exact values used), lanes (0–100 per lane) and detail (per-part scores).
  • composite_default and rank_default: the equal-weight composite and rank.
  • exhibition[]: Big AI Brain, shown on the track but not scored.
