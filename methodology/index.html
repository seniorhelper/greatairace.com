How the Great AI Race is scored

Six lanes, each scored 0–100 against the nine labs, averaged into one composite. Here is every rule.

Index change: Artificial Analysis switched to Intelligence Index v5 around Oct 28, 2026. v5 scores are not comparable to v4.x or earlier scores, so this race uses v5 only and never mixes versions.

The six lanes

LaneWhat it measures
MoneyValuation or market cap, plus annualized revenue run rate
ReachReported active users, plus share of worldwide gen-AI web traffic
BrainsArtificial Analysis Intelligence Index v5, plus Text Arena rank
MuscleLargest single AI data center by current IT power (Epoch AI estimates)
MomentumMajor model releases in the last six months
OpennessOpen-weight releases and how recent the latest one is

Normalizing each input

  • Linear inputs (AI index score, web traffic share, data center MW, release count): score = 100 × value ÷ best value among the nine labs.
  • Wide-range inputs (valuation, revenue, users) use a log scale so a $3.9T company does not flatten everyone else: score = 100 × (log10 v − log10(min ÷ 10)) ÷ (log10 max − log10(min ÷ 10)).
  • Text Arena rank: score = 100 × (1 − log10(rank) ÷ log10(200)), so #1 = 100, #3 ≈ 79, #113 ≈ 11. If a lab's overall rank is not published, Brains uses the AI index alone.
  • Openness: 0 with no open-weight model. With open weights, 50 points plus up to 50 more for recency: 50 × (1 − months since latest open release ÷ 12), floored at 0. If the release date is not verified, the lab gets the 50 base points only.
  • Lane score = average of that lane's available inputs. If none of a lane's inputs are disclosed, the lane scores 0 and shows "ND". That penalizes labs that publish less, and we say so on every card.

The composite formula

Composite = (w₁·Money + w₂·Reach + w₃·Brains + w₄·Muscle + w₅·Momentum + w₆·Openness) ÷ (w₁ + … + w₆)

Default weights are all equal (1). On the home page you can set each weight from 0 to 5 and the track re-ranks live. Your weights stay in your browser.

Known limits

  • Parent companies. Alphabet, Meta, Alibaba and SpaceX report company-wide valuation and revenue. AI is not broken out, so these labs score higher in Money than an AI-only figure would give them. The xAI valuation is SpaceX's total market cap.
  • Muscle uses the largest single data center by current IT power from Epoch AI. It undercounts distributed fleets (Google's TPUs) and does not count contracted future capacity.
  • Momentum counts major releases. Several counts are lower bounds. Growth figures are shown on fact cards but not scored, because labs report growth in different ways.
  • Sources. Some figures come from secondary reports of primary data (for example, summaries of Artificial Analysis data). Each fact card says so in its note.

Source conflicts we flag

  • Gemini users. Google reports 1 billion+ Gemini monthly active users (app + web, Oct 28 2026). Sensor Tower estimates 591M mobile-app MAU (Q3 2026). Different scope; we score Google's own figure and show both. blog.google
  • OpenAI valuation. $852B is the last confirmed primary round (Mar 2026). StockAnalysis shows a $993.7B implied secondary-market valuation (Oct 29 2026). We score the primary round. stockanalysis.com
  • OpenAI revenue. ~$50B run rate in Sept 2026 per FT/Reuters, about $20B below earlier company signals. sacra.com
  • OpenAI Abilene power. Epoch AI lists Stargate Abilene at 824 MW current IT power; OfficeChai (Nov 1 2026, citing Epoch) lists ~421 MW. officechai.com
  • Anthropic revenue. $65B run rate (Axios, Aug 2026). The S-1/A shows Q3 2026 revenue of $16.956B (about $67.8B annualized). Unverified reports claim more than $80B. indmoney.com
  • xAI valuation. The $2.0T figure is SpaceX's total market cap, not xAI alone. Share-price sources also disagree ($146.90 vs $134.97). stockanalysis.com
  • Qwen users. QuestMobile: 158.17M MAU (Sept 2026). Alibaba's annual report: 295M MAU across all platforms (Mar 2026). Different scope and method. sec.gov
  • DeepSeek valuation. Above $50B after its first outside round (Jun 2026). Unverified secondary claims of $74B exist. officechai.com
  • Mistral funding. Sacra lists a June 2026 "$3.5B at $20B" raise that is likely the same EUR 3B Series D reported by Orrick. orrick.com
  • Index versions. Grok 4.5 scored 54 and Kimi K3 scored 57 on the pre-v5 Artificial Analysis index. Those scores are not comparable to v5 and are not used. artificialanalysis.ai

Updates

All pages are built from one file, /data/race.json, designed to be refreshed by a nightly script. Feeds planned: Artificial Analysis Data API, Epoch AI data center data, OpenRouter rankings, the Text Arena dataset, the Hugging Face Hub API and SEC EDGAR. Similarweb, Sensor Tower and QuestMobile figures come from press coverage and are updated by hand. If a fetch fails, the last good value stays.

Independence

Great AI Race is independent. It is not affiliated with, endorsed by or sponsored by any lab shown. Not investment advice.
